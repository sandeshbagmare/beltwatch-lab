# Project context

BeltWatch Lab is a portfolio project about learning normal equipment dynamics from pixels. It is a reproducible research sandbox and offline demo for a synthetic conveyor, built in Python and PyTorch for an ordinary CPU. It has no camera integration, personal footage, model downloads, cloud inference, credentials, or actuators.

Start with the [design](docs/superpowers/specs/2026-11-20-beltwatch-design.md), [interface plan](docs/superpowers/plans/2026-11-20-beltwatch.md), [data card](data/README.md), and [status ledger](STATUS.md). The benchmark and demo are generated from the same tested entry point.
