# Working on BeltWatch Lab

Read [CONTEXT.md](CONTEXT.md), [STATUS.md](STATUS.md), and the [interface plan](docs/superpowers/plans/2026-11-20-beltwatch.md) before editing. Keep the default workflow on the CPU, offline after installation, and limited to generated equipment footage. Do not add live cameras, identifying data, credentials, network inference, or equipment controls. Do not send external messages.

Edit only the files assigned to you. Coordinate changes to shared files with the integrator, who owns commits and publication. Run a meaningful check before reporting completion, and append its result to STATUS.md without rewriting another contributor's evidence. Keep generated runs ignored. Published examples in `docs/assets` must come from a verified run.

Write documentation around what the code does and what the measurements support. Explain terms when a reader first needs them. Preserve the weak results and baseline comparisons, and distinguish an adaptation of a paper from a reproduction of it.
