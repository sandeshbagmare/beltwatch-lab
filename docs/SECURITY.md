# Scope and trust boundaries

The replay consumes only assets generated by this project. Training and the replay need no network connection after installation. There is no camera endpoint, browser upload, account, remote inference, or hardware control. Generated HTML embeds its own clip and score data; it does not fetch scripts or media from the Internet.

The CLI only writes into a new directory chosen by the runner. It does not open model files, accept serialized objects or execute code from input. It exports weights as safetensors. Treat any revised copy of the generated HTML as executable local content, just as you would a locally modified program.

Please report suspected issues through the repository's available GitHub reporting channel without including private data.
